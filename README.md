# media-incrementality-geo-lift-platform
Marketing measurement platform for estimating media incrementality using geo experiments, Difference-in-Differences, synthetic control, and conversion lift analysis.

This project is an in-progress marketing measurement platform designed to estimate the incremental impact of media campaigns across geographic markets.

The platform applies:
- Geo experiment design
- Difference-in-Differences
- Synthetic control methods
- Conversion lift analysis
- Incremental CPA and revenue impact measurement
- Budget optimization recommendations

## Business Problem

Marketing teams often need to understand whether paid media spend actually caused incremental conversions or whether those conversions would have happened anyway.

This project simulates a geo-based media experiment where selected treatment markets receive additional campaign spend while control markets do not. The goal is to estimate true campaign lift and translate the results into business recommendations.

## Planned Features

- Treatment vs control geo analysis
- Incremental conversion estimation
- Difference-in-Differences model
- Synthetic control comparison
- Geo-level lift dashboard
- Budget reallocation recommendations
- Executive summary for marketing stakeholders
